# GhanaWorks - React Native (Expo) scaffold

This folder contains a scaffold for the GhanaWorks React Native app (TypeScript + RTK + React Navigation v6) and a mock json-server backend for local development.

Quick start

1. Install dependencies

   cd ghanaworks
   npm run install:all

2. Start mock backend

   npm run start:server

   The mock server runs at http://localhost:3001

3. Start the Expo app

   npm start

Notes
- This scaffold is intentionally minimal; it provides a working store, navigation, example screens, and an offline queue slice placeholder.
- Expand the features (voice, maps, image compression) by adding the libraries and native setup as needed.
